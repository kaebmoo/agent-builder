- M19 (2026-10-31): deterministic `forge audit --security` checks `strict`, `secrets`, `packs` and `egress` (all error severity), following DESIGN §7. Promotion to `shippable` requires passing live evidence in the same run, matched compatibility and a clean strict static audit; a stored candidate is never reused. Reports add `audit.security` and `security_audit` (`status`, `strict`, `findings`, `scanned_files`, `detail`) with schema constraints on promotion and findings. This proves neither egress enforcement, runtime isolation, deployment nor human approval; guarantee-matrix rows remain unchanged.
