### Added

- M13 (2026-10-27): thClaws 0.138.0 host + bots layout, scoped adoption. DESIGN §4 records the `d452ece` facts (gui-gated auto-migrate, in-place rewrites of agent files, host proxy and child env, the single `workspace_dir` that serves identity, Atlas file handoff and `collect_files`, catalogue-only `bots add`) and §8 keeps deployed packages single-agent: operators start `thclaws --serve` with `THCLAWS_AUTO_MIGRATE=0` and never open a package in the desktop app. `builder/` becomes a host workspace (agent at `.thclaws/bots/main/`, runner addressed as `"$THCLAWS_AGENT_DIR/.thclaws/scripts/build.py"`, `build.py` finds the checkout by walking up and gains `--list-packs`). `forge/live_test.py` gains `isolated_env` and `check_layout`, used by every `--serve` start (M6/M7b/M8/M11), `request()` keeps SSE events as they arrive and detects stalls, and the M6 fake daemon has a migrated-layout negative case. New gate `check_m13_host_layout.py` (offline layout/harness/docs checks, native checks on any build, host/migration control only on a desktop build). The M11 live gate is now a two-turn interview (`weather-request.md` without confirmation, `weather-confirm.md` in the same session), requires `--model`, supports `--rounds`, and writes evidence per round; its live DoD is still open until three rounds pass on a Mac
- M11 (2026-10-26): builder-agent workspace `builder/` (a validated thClaws agent package with `spec-author` and `pack-author` skills and no subagents) whose only build path is `.thclaws/scripts/build.py`: it refuses a spec without a person's `confirmed_by` marker on permissions/env/capabilities, strips the marker, runs `forge pack test`, `forge generate` and `forge audit --write`, and prints verdicts from the build report; weather fixtures and `check_m11_builder_agent.py` (offline/native/live with explicit skips). The live interview has not been run yet
- M10 (2026-10-26): pack authoring workflow — `forge pack new` scaffolds a TODO-marked v2 descriptor, `forge pack discover` drafts `pack.yaml` from a live server's `tools/list` under a clean environment (tool inventory, surface digest, annotation-based `mutating` proposals; tier/network/fixture stay the author's decision), `forge pack test --packs-dir`, `docs/packs.md`, the `pack-author` skill under `builder/`, and the stdlib `echo` reference pack with an AgentSpec fixture; the harness now names the clean-environment rule when a server exits before replying
- M9 (2026-09-09): standalone `static-pipeline` T0 generation for planner/worker/verifier roles, native CLI live audit, per-role denial probes for Write/Edit/Bash, and a separate `--write-boundary` diagnostic that keeps T1 blocked when upstream writePaths traversal or symlink bypasses are present
- M8 (2026-09-08): `forge export` writes Atlas registration payloads, node/edge/policy templates, a schema-valid workflow definition (the T2 approval flow bound to operator worker/workspace ids) and a `thclaws agent pack` archive with a sha256 sidecar; the Atlas workflow-definition schema is pinned from atlas-control-plane `daa0f49`, and the M8 gate registers the export in an in-process Atlas and polls a packaged daemon. Export copies `package_status` and never verifies a deployment

- M7b (2026-09-08): publisher email/SFTP pack with explicit dry runs, fixed operator destinations, persistent idempotency keys and fail-closed handling of unknown delivery outcomes; T2 packages include a statically audited Atlas approval fragment requiring a dedicated daemon and explicit worker/workspace bindings. ### Fixed

- MCP harness on macOS: a server that exits before reading stdin now yields the same "exited before replying" reason on every platform instead of a `BrokenPipeError`, and process-group cleanup tolerates the `EPERM` macOS returns for an already-exited (zombie) group in both the pack harness and the live harness
- M9 upstream recheck: `0.129.0/7a27129` blocks parent traversal and existing symlink escapes, but a final dangling symlink can still escape `output/**`; the diagnostic now covers that case and T1 remains disabled
- M9 review follow-up 3: AgentSpec validation rejects built-ins that persist under `.thclaws/` (`TodoWrite`, `Memory*`, `Kms*` writers, `GuiShell*`) unless `write_scope` is `workspace`, so a documented CWD=package run can no longer leave a file the static audit reports as undeclared with no way to declare it; both live-audit copytree calls share one `COPY_IGNORE` set and the M6 gate checks source `state/` never reaches a run directory
- M9 review follow-up 4: static audit catches case variants of `.thclaws/state/todos.md`, while the live-audit copy filter is anchored to `.thclaws/state` and preserves a generated skill whose identity is `state`
- M9 review follow-up: static inventory now rejects added files inside `.thclaws/agents/` and `.thclaws/agent_workflow/`, closing the rogue-role bypass where an injected role could pass audit while exposing Write/Edit/Bash; the M9 gate now has negative cases for added role and workflow files, audit no longer ignores nested `__pycache__` payloads, `.thclaws/state/todos.md` or `.DS_Store`, standalone `AGENTS.md` edits require regeneration because role files embed the generated contract, and Atlas live audit no longer copies source `.thclaws/state/` into candidate runs
- T2 approval fragment derives its Atlas `outputs`/`collect_files` from the AgentSpec instead of a hardcoded artifact key (publisher package bytes unchanged)
- M8 review follow-up (2026-09-09): export refuses packages without a recorded passed static audit (and re-runs `thclaws agent validate` before packing when the report was written without the binary), refuses an export directory inside the package, normalises and rejects malformed base URLs, binds T2 placeholders structurally, and AgentSpec validation rejects Atlas input/`assistant_json` output names or non-object input schemas that Atlas `render_prompt`/artifact keys cannot render; the M8 gate compares the archive byte-for-byte except the two files thClaws rewrites, starts the daemon from the unpacked archive and fails on an unpinned Atlas ref; export now opens the packed archive and refuses it when `thclaws agent pack` silently stripped or altered any generated file (for example a `*_secret*` pack script or input name)
